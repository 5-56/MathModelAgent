# MathModel Agent Mobile - 本地AI使用指南

## 概述

MathModel Agent Mobile 现在支持完全本地化的AI推理，无需网络连接即可在移动设备上运行数学建模任务。本指南将帮助您配置和使用本地AI功能。

## 核心特性

### 🤖 本地AI模型
- **完全离线运行**：无需网络连接
- **多种模型支持**：Llama、Qwen、Phi、Gemma等
- **量化优化**：Q4量化模型，减少内存占用
- **快速推理**：基于ONNX Runtime优化

### 🧠 智能体系统
- **协调器**：分析问题并拆解任务
- **建模手**：建立数学模型
- **代码手**：编写Python代码
- **论文手**：生成完整论文

### 💻 Termux集成
- **完整Python环境**：numpy、pandas、matplotlib等
- **Jupyter Notebook**：交互式编程
- **文件管理**：本地文件系统访问

## 快速开始

### 1. 首次使用

1. **打开应用**：启动MathModel Agent Mobile
2. **进入模型管理**：点击"模型管理"按钮
3. **下载模型**：选择适合的模型并下载
4. **加载模型**：下载完成后点击"加载"
5. **开始对话**：进入"本地AI对话"开始使用

### 2. 推荐配置

#### 入门配置（2GB内存）
- **模型**：Phi-3 Mini 4K Instruct (Q4)
- **大小**：1.2GB
- **内存需求**：2GB
- **适用场景**：基础数学建模问题

#### 标准配置（4GB内存）
- **模型**：Qwen2.5 3B Instruct (Q4)
- **大小**：1.8GB
- **内存需求**：2.5GB
- **适用场景**：复杂数学建模和代码生成

#### 高级配置（6GB+内存）
- **模型**：Llama 3.2 3B Instruct (Q4)
- **大小**：2.1GB
- **内存需求**：3GB
- **适用场景**：专业级数学建模和论文写作

## 使用流程

### 1. 模型管理

#### 下载模型
1. 进入"模型管理"页面
2. 查看可用模型列表
3. 选择适合的模型
4. 点击"下载"按钮
5. 等待下载完成

#### 加载模型
1. 确保模型已下载
2. 点击"加载"按钮
3. 等待模型加载到内存
4. 加载完成后可开始使用

#### 切换模型
1. 在模型管理页面选择新模型
2. 点击"加载"按钮
3. 系统会自动卸载当前模型并加载新模型

### 2. 本地AI对话

#### 单智能体模式
1. 进入"本地AI对话"页面
2. 选择智能体类型：
   - **协调器**：问题分析和任务拆解
   - **建模手**：数学建模和方案设计
   - **代码手**：Python代码编写
   - **论文手**：论文写作
3. 输入问题并发送
4. 查看AI回复

#### 完整工作流模式
1. 选择"完整流程"模式
2. 输入数学建模问题
3. 系统自动运行所有智能体：
   - 协调器分析问题
   - 建模手建立模型
   - 代码手编写代码
   - 论文手撰写论文
4. 查看完整解决方案

### 3. Termux终端

#### 基本使用
1. 进入"Termux终端"页面
2. 执行Python命令：
   ```bash
   python3 --version
   pip list
   ```
3. 运行代码文件：
   ```bash
   python3 script.py
   ```

#### Jupyter Notebook
1. 启动Jupyter：
   ```bash
   jupyter notebook --ip=0.0.0.0 --port=8888
   ```
2. 在浏览器中访问：`http://localhost:8888`
3. 创建新的notebook进行交互式编程

## 故障排除

### 常见问题

#### 模型加载失败
**问题**：点击加载按钮后模型无法加载
**解决方案**：
1. 检查设备内存是否充足
2. 重启应用后重试
3. 选择更小的模型

#### 推理速度慢
**问题**：AI回复速度很慢
**解决方案**：
1. 关闭其他应用释放内存
2. 选择量化程度更高的模型
3. 减少输入文本长度

#### 模型下载失败
**问题**：模型下载过程中断
**解决方案**：
1. 检查网络连接
2. 确保存储空间充足
3. 重新开始下载

#### Termux无法启动
**问题**：终端页面无法正常显示
**解决方案**：
1. 确保已安装Termux应用
2. 检查Termux权限设置
3. 重启Termux应用
